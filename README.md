# 🎓 Placement Management System (MERN Stack)

A **centralized web-based Placement Management System** designed to streamline campus placement activities by connecting **students**, **placement administrators**, and **companies** on a single platform.

This system replaces manual Google Forms and spreadsheets with a **secure, scalable, and role-based solution**.

---

## 🚀 Project Overview

The Placement Management System helps colleges efficiently manage:
- Company visits
- Student eligibility & applications
- Placement statistics
- Verification and reporting

Built using the **MERN Stack**, the platform ensures transparency, real-time updates, and better decision-making for all stakeholders.

---

## 👥 User Roles

### 🛡️ Admin / Placement Officer
- Manage students, admins, and company users
- Post upcoming company drives
- Verify student profiles & documents
- Track placement statistics
- Generate placement reports
- Manage visited & non-visited companies

### 🎓 Student
- Complete profile & upload documents
- View eligible companies
- Apply for placement drives
- Track application status
- View placement history
- Monitor placement progress

### 🏢 Company
- Manage company profile
- View applicants
- Shortlist students
- Manage interview rounds
- View selected students

---

## ✨ Key Features

- 🔐 Role-based dashboards (Admin, Student, Company)
- 📊 Interactive dashboards & analytics

- 🧑‍🎓 Placement status tracking (Placed / Unplaced)
